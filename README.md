# TripsterKZ 🇰🇿

A native iOS application to discover, filter, and save the best travel tours across Kazakhstan.

## ✨ Features
* **Smart Filtering:** Instantly search tours by keyword or category (Nature, Culture, etc.).
* **Offline Favorites:** Save your dream destinations locally using **Core Data**.
* **Programmatic UI:** 100% code-based interface built with **SnapKit** (No Storyboards).

## 🛠 Tech Stack
* **Language:** Swift 5
* **UI Framework:** UIKit, SnapKit (Auto Layout)
* **Local Storage:** Core Data
* **Networking:** URLSession & Codable
